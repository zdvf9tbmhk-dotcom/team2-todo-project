# Выбор и настройка трекера

## Основной вариант: OpenProject Community Edition
Причины выбора: поддерживает назначение исполнителей, сроки, статусы, доски, процент выполнения, приоритеты и self-hosted развёртывание. Это напрямую соответствует формулировке задания.

## Состояния Kanban
`Новая` -> `Запланирована` -> `В работе` -> `На проверке` -> `Готово`.

## Поле прогресса
Используется `% complete`: 0 / 25 / 50 / 75 / 100.

## Интеграция
Git-репозиторий размещается в Gitea, сборка - Jenkins. Сервисы подготовлены в `infra/docker-compose.yml`.

## Ресурсы для согласования с преподавателем
Минимально для лабораторной команды: 4 vCPU, 8 GB RAM, 25+ GB свободного диска, Linux x86_64, Docker Engine + Compose Plugin, доступ по HTTP(S). Для длительной эксплуатации предпочтительно 8 vCPU / 12 GB RAM.

## Альтернативный вариант
Если кафедра не выдаёт VM: GitHub repository + GitHub Projects/Issues + GitHub Actions. Он проще, но хуже соответствует требованию self-hosted размещения на ресурсах кафедры.
