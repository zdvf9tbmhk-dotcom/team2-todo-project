# Правила разработки

- C++17, RAII и стандартная библиотека.
- 4 пробела, лимит строки 100; формат `.clang-format`.
- Имена классов `PascalCase`, методов/переменных `camelCase`, приватных полей с `_`.
- Не добавлять бизнес-правила в Qt slots: логика должна быть в `todo_core`.
- Любая новая функция сопровождается тестом ядра, если её можно проверить без GUI.
- Ветка `main` должна быть сборочной; изменения вносятся через feature branch + review.
- Commit message: `type: short description` (`feat`, `fix`, `test`, `docs`, `ci`, `refactor`).
- Перед merge: build + CTest обязаны быть зелёными.
