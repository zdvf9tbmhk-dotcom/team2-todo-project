# Сценарий сдачи проекта

1. Показать состав команды и роли.
2. Открыть `docs/AUDIT_LOG.md`, назвать ключевой дефект исходника с `centralWidget()` и отсутствие CMake/тестов.
3. Показать структуру репозитория и `CMakeLists.txt`.
4. Выполнить:
   ```bash
   cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
   cmake --build build
   ctest --test-dir build --output-on-failure
   ```
   Обратить внимание: тесты запускаются и в составе `cmake --build`.
5. Запустить `./build/todo_app`.
6. Продемонстрировать базовые функции: добавить задачу, отметить выполненной, прикрепить изображение, сохранить/загрузить JSON.
7. По очереди показать 5 новых фич:
   - редактирование;
   - удаление;
   - приоритет;
   - дедлайн/просрочка;
   - поиск + фильтр статуса.
8. Открыть `tests/test_main.cpp` и показать 8 тестов.
9. Открыть `.github/workflows/ci.yml` и/или Jenkins pipeline.
10. Показать `infra/docker-compose.yml`: OpenProject, Gitea, Jenkins.
11. В трекере показать участников, назначенные задачи, сроки, проценты выполнения и Kanban.
12. Завершить демонстрацией итогового статуса задач и готовности проекта.
