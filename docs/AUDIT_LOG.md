# Журнал анализа и ревизии исходного проекта

База анализа: `FujiwaraChoki/todo-list-cpp`, указанный в задании в качестве примера.

| № | Проблема исходного проекта | Риск/последствие | Исправление в Team 2 |
|---|---|---|---|
| 1 | Отсутствует `CMakeLists.txt` | Нет воспроизводимой сборки | Добавлен CMake с целями `todo_core`, `todo_app`, `todo_tests` |
| 2 | В конструкторе вызывается `centralWidget()->setLayout(...)` без предварительного создания central widget | Возможное обращение к `nullptr` и падение приложения | Создаётся `QWidget`, затем `setCentralWidget()` |
| 3 | UI, данные и файловая логика смешаны в одном классе | Сложно тестировать и расширять | Выделены `Task` и `TaskRepository`, независимые от Qt |
| 4 | Нет тестов | Регрессии не обнаруживаются автоматически | 8 тестов + CTest |
| 5 | Тесты не интегрированы в сборку | Проверка зависит от человека | CMake target `check ALL`, CI и Jenkins pipeline |
| 6 | Файлы `tasks.txt` и `cached_tasks.json` пишутся в текущий каталог | Непредсказуемое место хранения/ошибки прав | Кэш хранится в `QStandardPaths::AppDataLocation`; ручной JSON выбирается диалогом |
| 7 | Формат TSV ломается на табах/переносах и плохо расширяется | Потеря/искажение данных | Единый структурированный JSON |
| 8 | Нет проверки ошибок разбора JSON | Повреждённый кэш может вести к некорректному состоянию | Проверяется `QJsonParseError` и тип документа |
| 9 | Нет проверки индекса при переключении выполнения | Потенциальный выход за границы | Работа по стабильному ID через репозиторий |
|10 | Пустые/пробельные задачи допускаются косвенно | Некачественные данные | Trim + `invalid_argument` для пустого описания |
|11 | Отметка checkable выставляется только завершённым элементам | Непоследовательный UI | Каждый элемент получает check state |
|12 | Изображение хранится как абсолютный путь без проверки доступности | Превью может пропасть | При выборе проверяется загрузка; недоступность показывается пользователю |
|13 | Нет операций edit/delete | Пользователь не может корректировать список | Реализованы редактирование и удаление |
|14 | Нет приоритетов и сроков | Нельзя планировать важность и дедлайны | Добавлены priority и due date |
|15 | Нет поиска/фильтра | Список плохо масштабируется | Добавлены текстовый поиск и фильтр статуса |
|16 | Нет правил оформления/CI | Разные окружения дают разные результаты | `.clang-format`, предупреждения компилятора, GitHub Actions, Jenkinsfile |
