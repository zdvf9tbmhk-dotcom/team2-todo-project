# Техническое задание

## 1. Цель
Модернизировать исходное Qt/C++ приложение списка задач так, чтобы оно имело воспроизводимую CMake-сборку, автоматические тесты, пять новых функций, контроль качества и готовую инфраструктуру командной разработки.

## 2. Функциональные требования
- создание задачи с непустым описанием;
- просмотр списка;
- отметка выполнения двойным щелчком;
- прикрепление изображения;
- автоматическое кэширование в JSON и ручной импорт/экспорт;
- **F1:** редактирование выбранной задачи;
- **F2:** удаление выбранной задачи с подтверждением;
- **F3:** приоритет Low/Normal/High;
- **F4:** срок выполнения и индикация просрочки;
- **F5:** поиск по описанию и фильтрация по статусу.

## 3. Нефункциональные требования
- C++17;
- Qt Widgets (Qt 6 предпочтительно, Qt 5 допускается CMake-конфигурацией);
- CMake >= 3.21;
- Linux/Windows совместимость;
- предупреждения компилятора включены;
- бизнес-логика не зависит от GUI;
- тесты выполняются автоматически во время сборки;
- код форматируется по `.clang-format`.

## 4. Критерии приёмки
1. `cmake` успешно конфигурирует проект при наличии Qt.
2. `cmake --build` собирает приложение и запускает CTest.
3. 8 тестов ядра завершаются без ошибок.
4. Каждая из пяти новых функций демонстрируется по сценарию сдачи.
5. JSON корректно сохраняется/загружается, повреждённый JSON обрабатывается сообщением об ошибке.
