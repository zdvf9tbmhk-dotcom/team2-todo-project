# Архитектура

`todo_core` не зависит от Qt и содержит модель `Task` и `TaskRepository`. Благодаря этому бизнес-правила тестируются обычным C++ тестовым исполняемым файлом. `todo_app` отвечает только за Qt Widgets, преобразование пользовательского ввода и JSON persistence. CTest запускает `todo_tests`.

Такое разделение устраняет главную проблему исходного варианта: UI, состояние и файловая логика больше не сосредоточены в одном классе.
