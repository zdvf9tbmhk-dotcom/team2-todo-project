# План тестирования

## Автоматические тесты

| ID | Проверка | Ожидаемый результат |
|---|---|---|
| T01 | Добавление задачи с пробелами по краям | Описание нормализовано |
| T02 | Добавление строки из пробелов | Исключение/отказ |
| T03 | Двойное переключение статуса | active -> complete -> active |
| T04 | Редактирование описания, приоритета и срока | Поля обновлены, ID сохранён |
| T05 | Удаление | Задача отсутствует в репозитории |
| T06 | Поиск и фильтр статуса | Возвращается только подходящее подмножество |
| T07 | Просроченный срок | Active задача со старой датой помечается просроченной |
| T08 | Импорт задач с ID | Следующий ID больше максимального импортированного |

## Ручные GUI-проверки
1. Добавить три задачи разных приоритетов.
2. Назначить одной задаче вчерашний срок и проверить `ПРОСРОЧЕНО`.
3. Изменить описание и срок выбранной задачи.
4. Удалить задачу и отменить/подтвердить удаление.
5. Найти задачу по части текста.
6. Переключить фильтр Активные/Выполненные.
7. Прикрепить PNG/JPEG и проверить preview.
8. Сохранить JSON, очистить/перезапустить приложение и загрузить JSON.
9. Открыть повреждённый JSON и убедиться, что приложение не падает.
